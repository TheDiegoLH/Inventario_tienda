# Inventario_tienda

Sistema de inventario en Python que permite agregar y vender productos, mostrar inventario, consultar el más caro, ver estadísticas y detectar bajo stock. Incluye validaciones, manejo de errores y un menú interactivo para gestionar todo desde consola.

## Instrucciones de uso
1. Descarga o clona este repositorio.
2. Abre una terminal en la carpeta donde está el archivo `inventario_tienda.py`.
3. Ejecuta el programa con:
   ```bash
   python inventario_tienda.py
